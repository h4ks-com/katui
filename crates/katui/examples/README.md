# katui examples

These are the two smallest katui programs, written against the `katui` facade crate.

### counter

A label and a button that counts its clicks. It shows the smallest UI app: a view, a message and an update.

Run it with `just demo-counter`. Click the button to add one, and press Ctrl+C to quit.

<img src="screenshots/counter.webp" alt="A panel reading Clicked 3 times above an Add one button" width="720">

### glow

A glowing ball you steer left and right. It shows the smallest game: a step function, a render function and held keys.

Run it with `just demo-glow`. Hold Left or Right to move the ball, and press q, Esc or Ctrl+C to quit.
