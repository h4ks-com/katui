How the renderer works

  1. The parser builds the document tree.
  2. Style rules match through CSS selectors and cascade by specificity.
  3. Each block becomes a container, and each run of inline text becomes styled text.
  4. The layout engine places everything with flexbox, and the terminal shows it as images.
The subset covers block and flex layout, inline text styles, images and links.
